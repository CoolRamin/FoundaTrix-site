# Contributing

This repository holds only the FoundaTrix Studio **website**. It does not accept contributions to
the program itself, whose source lives in a separate, private repository.

## Reporting a bug or asking for a feature in the program

This repository's Issues are the public tracker for the **program** as well as the site. Open an
issue and choose **Bug report** or **Feature request**; no access to the program's code is needed.
Search first: the issue may already be open, and a thumbs-up on it tells us it matters to you too.

Keep confidential project data out of public issues. For anything that cannot be public, email
`admin@ramisoftsolutions.com`.

## Typo fixes and small edits to the site

Open a pull request against `src/`. Keep every `href` and `src` root-absolute (`/styles.css`, not
`styles.css`), since the pages live in folders.

## Larger changes to the site

Open an issue first to discuss what you would like to change, so effort is not wasted on something
that does not fit the site's direction.
